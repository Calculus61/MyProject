တပ်မတော်(ရေ)

  • မူလစာမျက်နှာ
  • အကြောင်းအရာ
  • လေ့ကျင့်ခန်းများ
  • မှတ်တမ်းဓာတ်ပုံများ

ရေတပ်စစ်နည်းဗျူဟာ စစ်ကစားမှုလေ့ကျင့်ရေးခန်းမ

တပ်မတော်(ရေ)ရှိ အရာရှိ၊ စစ်သည်များအား ပင်လယ်ပြင်စစ်ဆင်ရေးတာဝန်ထမ်းဆောင်ချိန်တွင်

စစ်ဆင်မှုနယ်ပယ်(၄)ရပ်ကို ကျွမ်းကျင်ပိုင်နိုင်စွာဖြင့် လေ့ကျင့်ပေးရန်။

ASTT ဆိုင်ရာ အချက်အလက်များ

  • ရေတပ်လေ့ကျင့်ရေးဌာနချုပ်ဌာနချုပ်ရှိ လက်နက်နှင့်လက်နက်စနစ်သင်တန်းဌာနတွင် Maritime Wargame Center အပြင် အဆင့်မြှင့်တင်ထားသော ရေတပ်စစ်နည်းဗျူဟာ စစ်ကစားမှုလေ့ကျင့်ရေးခန်းမ Action Speed Tactical Trainer- ASTT (Wargame Simulator) အား အိန္ဒိယနိုင်ငံ၊ Messrs Anawave Systems and Solutions Pvt., Ltd ထံမှ ဝယ်ယူရန်ဆောင်ရွက်ခဲ့သည်။
  • ဝယ်ယူရေးအတွက် စာချုပ်လက်မှတ်ရေးထိုးခြင်းကို ၂၀-၈-၂၀၂၁ တွင်ဆောင်ရွက်ခဲ့သော်လည်း ကမ္ဘာတစ်ဝှမ်းဖြစ်ပွားခဲ့သည့် ကိုဗစ်-၁၉ ရောဂါကြောင့် တပ်ဆင်ခြင်းလုပ်ငန်းများ နှောင့်နှေးခဲ့ပါသည်။
  • Software အား စစ်ဆေးရန်အတွက် တပ်မတော်(ရေ)မှ ဗိုလ်မှူး အောင်အောင်၊ ဗိုလ်မှူး ကျော်ဇေယျ နှင့် ဗိုလ်ကြီး ထူးမောင်မောင်တို့ အရာရှိ ၃ ဦးအား အိန္ဒိယနိုင်ငံ၊ Bangalore မြို့သို့ ၂၄-၃-၂၀၂၂ ရက်နေ့မှ ၂၉-၃-၂၀၂၂ ရက်နေ့အထိ စေလွှတ်ခဲ့ပါသည်။
  • ASTT အဆောက်အဦးဆောက်လုပ်ပြီးနောက် ကွန်ပျူတာများတပ်ဆင်ဆောင်ရွက်ခြင်းလုပ်ငန်းကို အိန္ဒိယနိုင်ငံမှ ပညာရှင် ၅ ဦးဖြင့် ၄-၈-၂၀၂၅ မှ ၁၃-၈-၂၀၂၅ ထိဆောင်ရွက်ခဲ့ပါသည်။
  • အိန္ဒိယနိုင်ငံ ဒုတိယရေတပ်ဦးစီးချုပ်မှ ရေတပ်စစ်နည်းဗျူဟာ စစ်ကစားမှုလေ့ကျင့်ရေးခန်းမအား ၂၈-၉-၂၀၂၅ ရက်နေ့တွင်လွှဲပြောင်းပေးအပ်ခဲ့ပါသည်။
  • ASTT တွင် အဓိကအားဖြင့် Server Site နှင့် Client Site ဟူ၍ ၂ မျိုးခွဲခြားထားပြီး Linux OS ဖြင့် မောင်းနှင်ခြင်းဖြစ်ကာ Web Base ပေါ်တွင် အခြေခံအသုံးပြုထားသောကြောင့် မည်သည့် Windows တွင်မဆို Google Chrome Web Browser ဖြင့် ဝင်ရောက်ကစားနိုင်သည်။
  • Server Site တွင် Game Control အတွက် Computer ၃ လုံး အသုံးပြုထားပြီး Computer ၁ လုံးစီအတွက် Monitor ၃ လုံးစီ ပါရှိသောကြောင့် Server Site တွင် စုစုပေါင်း Computer ၃ လုံးနှင့် Monitor ၉ လုံးရှိပါသည်။
  • Client Site တွင် အပြာရောင်တပ်ဖွဲ့အတွက် Computer ၁၁ လုံး၊ အနီရောင်တပ်ဖွဲ့အတွက် Computer ၁၁ လုံးစီပါရှိပြီး Computer ၁ လုံးစီအတွက် Monitor ၂ လုံးစီပါရှိသောကြောင့် Client Site တွင် စုစုပေါင်း Computer ၂၂ လုံးနှင့် Monitor ၄၄ လုံး ရှိပါသည်။
